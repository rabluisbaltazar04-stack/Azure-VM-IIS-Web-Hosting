# Azure VM and IIS Web Hosting

**School activity | Platform Technology | August 2026**

## About this activity

For one of our Platform Technology activities, I tried using Microsoft Azure to create a Windows virtual machine and host a simple website. I connected to the VM using Remote Desktop, installed IIS (Internet Information Services), and used it to host my HTML/CSS portfolio website.

It was my first experience setting up a web server inside a cloud VM instead of just running a website on my own computer.

## Tools I used

- Microsoft Azure and Azure Virtual Machines
- Windows Server and Remote Desktop (RDP)
- IIS / IIS Manager
- HTML and CSS

## Output

I was able to open the website in a browser using the VM's public IP address during the activity. Here's a screenshot of one of the pages I hosted:

## What I learned

This activity helped me understand how a cloud VM works, how to connect to it remotely, and how IIS can serve a website. I also learned that cloud resources need to be managed carefully because they can use up trial credits or incur charges.

I disabled Windows Defender Firewall during the original classroom activity while checking website access. If I do this again, I would keep the firewall enabled and allow only the necessary web traffic instead.

**Note:** This was a school activity using an Azure free trial. The VM and other Azure resources have already been deleted, so the website is no longer hosted there.
